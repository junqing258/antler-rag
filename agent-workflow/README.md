# 工作流配置说明

此目录保存多 Agent 工作流的版本化规则；运行时产生的方案、审核和日志不在这里，而在被 Git 忽略的 `.agent-runs/` 中。

| 文件 | 用途 |
| --- | --- |
| `design.md` | Codex 方案设计阶段的职责、边界和质量要求。 |
| `review.md` | Claude Code 审核阶段的独立性和批准标准。 |
| `implement.md` | 人工批准后 Codex 实施阶段的约束。 |
| `protocol.md` | 两个 Agent 共享的产物、状态机和所有权约定。 |
| `schemas/*.json` | 方案与审核的机器可读输出结构。 |

修改角色规则时，应同时考虑 JSON Schema 是否仍能表达所需信息。角色规则变更会影响后续所有任务，建议与业务代码一样经过审查并在提交说明中记录原因。
